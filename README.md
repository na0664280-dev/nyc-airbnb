# تحليل أسعار Airbnb في نيويورك

## المشكلة
المستخدم يبي يعرف السعر المناسب لإعلانه حسب المنطقة ونوع الغرفة.

## الداتا
48,631 إعلان Airbnb في نيويورك (clean.csv).

## أهم الاكتشافات
- Manhattan الأغلى (متوسط ≈ 180) وBronx الأرخص (≈ 85)
- الشقة الكاملة أغلى من الغرفة الخاصة بحوالي 2.5 مرة
- Manhattan وBrooklyn فيهم أغلب الإعلانات

## رابط التطبيق

## طريقة التشغيل
pip install -r requirements.txt
streamlit run app.py
